# 瀚霖创作引擎 · UI/UX 规范

> 版本：v1.1 ｜ 日期：2026-07-25 ｜ 状态：设计与研发共同基线
>
> 上游依据：[产品 PR](./瀚霖创作引擎-产品PR文档.md) 与 [全量产品体验与页面设计方案](./瀚霖创作引擎-全量产品设计方案.md)。本规范约束可实现的视觉、交互、内容与无障碍行为；产品范围和里程碑仍以 PR 为准。

## 1. 体验原则

1. **先给下一步，再给全部能力。** 首页和侧栏优先呈现“继续第 N 章”“确认蓝图”“处理 2 条变化”等行动，不让用户从功能目录猜测流程。
2. **正文是工作核心。** 编辑器正文永远拥有最大视觉面积。运行状态、事实和评审只有在关联本章或需要裁决时出现。
3. **AI 的建议可看、可改、可回退。** 建议与作者确认内容必须视觉区分；改变已确认事实、当前指针或导出范围的操作必须说明影响。
4. **状态在发生处可见。** 保存、生成、重试、恢复、定稿分别在按钮附近和任务中心呈现。不可只依赖瞬时 Toast 或日志。
5. **克制而可靠。** 用细分隔线、稳定栅格和明确文字建立信任，避免大面积渐变、装饰性光晕、夸张圆角和营销式卡片堆叠。

## 2. 令牌与排版

业务页面使用 `packages/ui` 的语义变量；下列值是设计令牌来源，不在页面组件中直接硬编码。

| 类别     | Token               | 值        | 使用                        |
| -------- | ------------------- | --------- | --------------------------- |
| 画布     | `--hl-canvas`       | `#F7F9F8` | 应用背景、侧栏底色          |
| 表面     | `--hl-surface`      | `#FFFFFF` | 主内容、Sheet、菜单         |
| 强文本   | `--hl-ink`          | `#17201D` | 标题、正文、图标            |
| 弱文本   | `--hl-muted`        | `#62716A` | 说明、元数据、未激活项      |
| 分隔     | `--hl-line`         | `#D7DFDA` | 边框、分隔线、Skeleton 容器 |
| 主色     | `--hl-primary`      | `#087F5B` | 主操作、当前导航、完成      |
| 主色弱化 | `--hl-primary-soft` | `#EAF5EF` | 选中背景、低强调成功        |
| 进行中   | `--hl-info`         | `#2563EB` | 运行、可恢复、信息          |
| 警示     | `--hl-warning`      | `#B45309` | 待确认、需要检查、预算提醒  |
| 阻断     | `--hl-danger`       | `#B91C1C` | 硬冲突、失败、危险操作      |

| Token           | 值                              | 规则                                         |
| --------------- | ------------------------------- | -------------------------------------------- |
| `--space-*`     | 4, 8, 12, 16, 24, 32, 40, 48 px | 仅用此 4 px 基准递增，不随页面临时发明间距   |
| `--radius-sm`   | 4 px                            | 输入、紧凑菜单                               |
| `--radius-md`   | 6 px                            | 按钮、Sheet 内单个内容对象                   |
| `--radius-card` | 8 px                            | 作品、任务、版本等重复对象；页面区块不加卡片 |
| UI 正文         | 16 px / 1.5                     | 表单、按钮、导航                             |
| 辅助文字        | 14 px / 1.5                     | 描述、时间、状态原因                         |
| 区块标题        | 18 px / 1.35                    | 页面内部层级                                 |
| 页面标题        | 28 px / 1.25                    | 每页仅一个                                   |
| 创作正文        | 18 px / 1.8                     | 最大行宽 860 px，字距 `0`                    |

文本与背景、状态文字与状态背景均须达到 4.5:1 对比度。颜色不是唯一状态载体：运行、成功、警告、失败均使用图标、明确标签和色彩三重表达。

## 3. 应用壳与响应式

| 视口         | 壳结构                                                              | 强制行为                                                                   |
| ------------ | ------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| >= 1440 px   | 320 px 全局侧栏 + 主区；写作页可有 240 px 章节栏、正文、320 px 上下文栏 | 正文宽度不超过 860 px；右栏可收起                                          |
| 1024-1439 px | 240 px 作品侧栏 + 主区                                              | 上下文栏默认收起为 Sheet；工具栏不换行遮挡正文                             |
| 768-1023 px  | 主区 + 侧栏抽屉                                                     | 保留阅读、轻编辑、事实裁决；复杂 diff 不并排展示                           |
| < 768 px     | 单列                                                                | 可查看、裁决、轻量编辑；生成和版本比较明确引导到桌面，不使用无解释禁用按钮 |

顶栏高 64 px，承载面包屑、全局搜索、`新建作品`、任务、帮助和账户。侧边栏只展示稳定页面目录；项目进度、下一步、任务列表、章节树和事实裁决都留在对应页面。路由改变时必须同步更新面包屑、当前侧栏项、浏览器标题和 `aria-current="page"`。

## 4. 组件契约

| 组件               | 结构与尺寸                                     | 必须状态                                         | 交互规范                                                                         |
| ------------------ | ---------------------------------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------- |
| `AppSidebar`       | 品牌、稳定导航组、底部账户                     | 展开、图标收起、当前、无作品                     | 只放路由链接；收起时每项有 Tooltip；不显示搜索、创建、动态项目、任务计数或下一步 |
| `ProjectNav`       | 返回作品库、项目标题、四个功能分组             | 当前、无数据、只读、归档                         | 固定显示创作准备、章节创作、内容管理、交付；不放进度、动作或章节树               |
| `ChapterNavigator` | P07 工作台内的章节树                           | 当前、计划待确认、草稿、定稿、需复核             | 只在创作页出现，默认定位当前章节                                                 |
| `PageHeader`       | 面包屑、H1、状态、主操作、更多菜单             | 加载、只读、受限、运行中                         | 每页只有一个主操作，依据项目状态变化                                             |
| `ProjectRow`       | 标题、文体、进度、最近活动、下一步、风险、菜单 | 默认、悬停、选中、归档、错误                     | 点击整行打开作品；菜单中的删除必须二次确认                                       |
| `WritingEditor`    | 标题/目标、文字命令、正文、底部元信息          | 空、编辑、保存中、仅本地、流式、历史只读、已定稿 | 750 ms 防抖保存；选区操作永远产生新修订，不原地替换                              |
| `ContextPanel`     | 计划、事实、问题三个标签                       | 空、存在待办、加载、不可用                       | 仅显示与当前章相关内容；窄屏改为 Sheet                                           |
| `DecisionSheet`    | 标题、证据、原值到建议值、动作区               | 待裁决、接受、编辑后接受、拒绝、阻断             | 关闭不丢裁决进度；“全部接受”只用于同类低风险项                                   |
| `TaskCenter`       | 分组任务行、进度、错误摘要、行动               | 运行、失败、可恢复、完成、取消                   | 失败卡必须说明已保存内容、恢复点和下一步                                         |
| `VersionCompare`   | 版本选择器、差异正文、影响摘要、恢复操作       | 单版、双版、加载、不可比较、恢复中               | 恢复前说明当前指针、下游影响；不能删除历史                                       |
| `EmptyState`       | 短标题、单句解释、主/次操作                    | 首次、筛选无结果、权限不足                       | 不写长篇教学，不把空态做成营销页                                                 |

按钮只分四种意图：`Primary` 用于生成、确认、导出等明确命令；`Secondary` 用于同级但低强调操作；`Ghost` 用于页面内导航；`Destructive` 用于删除、强制导出和不可逆操作。带文字的按钮用于命令，图标按钮只用于撤销、重做、收起、关闭、更多等熟悉工具，并必须有 Tooltip 和可访问名称。

### 4.1 小说转剧本组件与状态

小说转剧本不是在小说编辑器中弹出的长表单。它使用 P13 改编蓝图页与 P12 场景工作台，始终把“来源、取舍、输出”并列可见；原作正文和剧本文字不做逐字并排比较。

| 组件 | 内容 | 必须状态 | 交互约束 |
| --- | --- | --- | --- |
| `AdaptationEntry` | 来源小说、可改编章节、授权确认 | 无定稿、无权限、可创建 | 只在符合前置条件的小说页显示；不可用状态说明缺少定稿或权限 |
| `AdaptationBrief` | 目标形态、集数、单集时长、受众、保留重点 | 草稿、校验错误、已确认 | 提交前显示将创建的来源快照和预计产物；不允许默认勾选授权声明 |
| `AdaptationDecision` | 原作锚点、取舍类型、理由、受影响场景 | 待确认、已接受、已编辑、已拒绝、需复核 | 每项可回链来源；高影响合并/删减必须要求理由，不能批量接受 |
| `SourceSceneMapping` | 原作事件与剧本场景的对应关系 | 已映射、待映射、来源过期、冲突 | 点击任意一端同步定位；来源更新只标记过期，不自动重写剧本 |
| `ScenePlanBoard` | 集/幕、场景目标、冲突、出场人物、时长 | 草稿、待确认、已确认、受影响 | 确认后生成场景剧本；变更影响后续场景时明确显示数量 |
| `ScreenplayEditor` | 场景头、动作、角色、对白、括注、修订 | 编辑、保存中、历史只读、格式阻断 | 用结构化剧本元素而非普通富文本；每次 AI 生成创建新场景修订 |

在改编项目内，来源快照版本固定显示于页头。任何“重新同步原作”命令必须先显示差异与受影响场景，确认后创建新快照；禁止将源小说更新静默带入剧本。

## 5. 状态、反馈与错误

| 场景          | 发生处反馈                               | 任务中心         | 用户可执行动作                   |
| ------------- | ---------------------------------------- | ---------------- | -------------------------------- |
| 自动保存      | “保存中”后显示具体时间                   | 不记录常规保存   | 继续编辑                         |
| 网络中断      | “仅本地草稿，等待同步”静态提示           | 不创建失败任务   | 重试同步、复制正文               |
| 生成中        | 增量文本、阶段、字数、停止               | 运行中任务       | 停止、查看输入、后台继续         |
| 生成失败      | 内联错误和保留的输入/已有文本            | 失败或可恢复任务 | 重试、从检查点继续、返回编辑     |
| 事实/评审阻断 | 定稿按钮下显示准确原因                   | “待你处理”       | 打开对应裁决或问题               |
| 定稿补偿中    | 顶部明确“已保存正文，正在完成摘要/索引”  | 可恢复任务       | 继续完成、保留草稿、查看详情     |
| 导出受限      | Sheet 显示未定稿章节和 P0 问题           | 可选审计记录     | 仅导出已定稿，或填写强制原因     |
| 无权限        | 不显示不可用导航项；直链页面显示权限说明 | 无               | 返回有权限页面、联系工作区管理员 |
| 改编来源过期  | 页头显示来源版本与受影响场景数           | 待你处理         | 查看差异、创建新快照、逐场复核   |
| 改编生成失败  | 保留简报、取舍和已完成场景               | 可恢复任务       | 从最后完成场景继续、查看输入      |

Toast 只用于“导出已完成”“恢复完成”“操作失败”等短反馈；它不得承担保存成功、生成状态、阻断原因或恢复入口。加载 Skeleton 的外形必须与最终内容相同，避免页面加载后跳动。

## 6. 内容与文案

界面说作者需要理解的话，避免暴露实现：

| 不使用                     | 使用                                      |
| -------------------------- | ----------------------------------------- |
| 运行时、Run、Agent、Schema | 生成任务、创作助手、作品设定、章节计划    |
| 写入 Fact                  | 记录为已确认设定                          |
| `FAILED`                   | 生成未完成，可从保存的位置继续            |
| 覆盖版本                   | 将此版本设为当前草稿/当前定稿             |
| 冲突对象 ID                | 第 3 章与已确认的“林砚左臂受伤”设定不一致 |

错误文案使用“发生了什么 + 已保存什么 + 下一步怎么做”三段信息。例如：`摘要更新未完成。正文和事实裁决已保存。你可以继续完成定稿，或先保留为草稿。` 禁止只显示“请求失败”“操作异常”或技术错误码；错误详情可在“查看技术详情”中折叠呈现。

表单只在字段附近显示校验结果。创建作品的最低必填项是主题/梗概和题材；字数、章节数、模型和风格使用符合场景的默认值并可稍后编辑。关闭未提交的创建/导入/编辑流程时，提示“保存草稿 / 放弃”，默认焦点在安全选项。

## 7. 键盘、焦点与读屏

| 操作         | 快捷键                 | 焦点与读屏                          |
| ------------ | ---------------------- | ----------------------------------- |
| 打开命令面板 | `Cmd/Ctrl + K`         | 焦点进入搜索框；Esc 回到原触发点    |
| 保存草稿     | `Cmd/Ctrl + S`         | 简短 `aria-live` 播报保存结果       |
| 生成草稿     | `Cmd/Ctrl + Enter`     | 只在计划确认且非 IME 组合输入时触发 |
| 切换上下文   | `Cmd/Ctrl + .`         | `aria-expanded` 与可见状态同步      |
| 打开问题     | `Cmd/Ctrl + Shift + P` | 焦点移至第一个未解决问题            |
| 查看来源证据 | `Cmd/Ctrl + Shift + M` | 同步定位原作锚点并播报来源章节      |

Sheet 和 Dialog 打开后锁定焦点，关闭后回到触发元素。流式正文不逐字播报；仅播报阶段变更、完成、失败和可恢复。所有交互目标至少 40 x 40 px，Tab 顺序与视觉顺序一致，焦点环始终可见。

## 8. UI QA 清单

- 每个页面有空、加载、错误、权限不足和可恢复失败状态，且不清空已保存内容。
- 每个按钮、状态徽标、图标按钮和链接都有明确的可访问名称；图标不作为唯一命令。
- 侧栏当前项、章节状态和待办计数在展开/收起、刷新、路由返回后保持一致。
- 所有危险操作说明影响范围，并提供取消；默认焦点不落在危险操作上。
- 1024 px、768 px 和 375 px 下不存在文字截断遮挡、控件重叠或不可达操作。
- 事实与评审问题能从列表跳到正确章节和证据；版本恢复和导出都能回到来源记录。
- 使用键盘可完成“创建作品 -> 确认蓝图 -> 生成草稿 -> 裁决变化 -> 定稿 -> 导出”完整路径。
- 使用键盘可完成“选择定稿小说 -> 确认改编简报 -> 裁决一项取舍 -> 确认场景计划 -> 生成场景剧本 -> 回链来源 -> 导出”完整路径。
