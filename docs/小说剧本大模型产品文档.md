# 第一部分：小说/剧本 AI Agent 竞品调研

## 1.1 国内小说写作 Agent

### 1. 唐库（Tanglib）全自动小说生成平台
- **定位**：AI 长篇小说一站式创作平台，面向文学创作者、版权机构及网文平台。
- **核心能力**：
  - 「全自动生成引擎」：输入核心设定后，自动完成世界观搭建 → 大纲生成 → 章节细化 → 正文输出的全流程，宣称可单日产出百万字级网文。
  - 宣称突破长文本生成中的「逻辑断层」与「角色崩坏」问题。
  - 行业首创「小说调校工具」：在大纲阶段人类可介入，对角色性格、行文风格、剧情走向、细节描写精细干预，让 AI 自我检验并修正后续情节逻辑；正文生成后提供一键逻辑/连贯性校验。
- **理念**：「AI 主导生成，人类主导审美」的人机协同。
- **启示**：全自动流水线 + 人工调校双引擎是行业标杆形态；「一键校验」已成标配预期。

### 2. 灵咔灵咔（华东师范大学团队）
- **定位**：高校背景的超长篇小说生成智能体。
- **核心能力**：标签化选题（如「玄幻+复仇+系统流」）→ 自动生成剧情动力、角色设定、100 章大纲；官方宣称 80 分钟生成 30 万字初稿，人工干预约 10%。
- **特色**：多模态融合 —— 同步生成角色图、世界观地图（宗门分布、法器图谱）。
- **短板**：情感线易偏离预设（如「青梅竹马虐恋」写成「兄妹情深」），需人工纠偏。
- **启示**：标签驱动的低门槛入口 + 多模态素材是差异化方向；情感线一致性是行业共性难题。

### 3. 量子探险
- **定位**：面向网文作者的长篇一键成书软件。
- **核心能力**：一键生成 600 章大纲及 200 万字正文；全品类覆盖（玄幻、言情、都市、悬疑等热门网文类型）。
- **启示**：「长度军备竞赛」已是国内网文工具的主要卖点，但长度不等于质量，质量校验才是护城河。

### 4. 百度作家平台
- **定位**：背靠百度、与自家小说平台（七猫等）强联动的「官方外挂」。
- **核心能力**：灵感获取、长篇拆书、超详细大纲范例、正文生成一站式服务；内置写作模板，对新人友好；投稿流量扶持。
- **短板**：功能联动不够丝滑，生成内容偏「标准化」，需二次加工。
- **启示**：「创作 + 分发/投稿」闭环是平台型玩家的核心优势。

### 5. 蛙蛙写作 / 星月写作 / 笔灵AI 等
- **蛙蛙写作**：免费起步 + 社区 Prompt 共享氛围浓；生成质量波动大。
- **星月写作**：网文适配度、情感描写细腻度、长文一致性评价较高（横评中多项 4-5 星）。
- **通用大模型直接写作**：DeepSeek（大纲与设定生成强）、Kimi（长上下文续写一致性好，20 万字级上下文）、Claude（文学性与情感细腻度强，单次输出可达 3900 字连贯文本）、Gemini（网感强、反转密集）、ChatGPT（头脑风暴与多方案发散强）。
- **启示**：通用大模型正在「免费吃掉」浅层写作需求，垂直产品必须在长文一致性、类型化套路、工作流深度上建立壁垒。

### 6. 开源参考：ainovel-cli（GitHub，多 Agent 架构）
- **架构**（极具参考价值）：Coordinator 驱动三个子代理完成整书创作 —
  - **Architect**：从一句话需求推导完整设定；负责骨架规划与「滚动式」分卷展开（指南针 Compass：终局方向 + 活跃长线 + 规模估计；骨架弧到时再细化）。
  - **Writer**：每章固定闭环 `加载上下文 → 回读前文 → 规划本章 → 写作 → 一致性检查 → 提交`。
  - **Editor**：弧级评审，跨章分析结构问题，输出裁定与重写范围。
- **自动伏笔管理**：埋设、推进、回收全程 Agent 自行追踪；自动节奏调控避免连续章节结构雷同。
- **启示**：这是当前长篇小说 Agent 最先进的开源架构范式，可直接作为我们的架构蓝本。

## 1.2 海外小说写作工具

### 7. Sudowrite
- **定位**：小说家专用 AI 协作写作工具（Pro 约 $19/月）。
- **核心能力**：场景扩写（Expand Scene）、「Describe This」感官描写、角色卡记忆、Lorebook（设定集）、章节级连续性追踪、Sensitivity Mode（敏感主题审查）。
- **实测表现**：15 个场景内角色声音保真度约 89%；对话密集场景需显式引导。
- **短板**：多语言支持弱、Lorebook 需手动维护。
- **启示**：「角色卡 + Lorebook + 连续性追踪」三件套是海外小说工具的标配内存结构。

### 8. NovelAI
- **定位**：深度世界观 + 文风实验型工具（约 $9.99/月）。
- **核心能力**：深度世界观记忆、自定义模型微调（KoboldCPP）、诗性/抒情生成强。
- **短板**：学习曲线陡峭；12 个场景后连续性评分降至 62%，需手动强化设定。
- **启示**：自定义微调（个人文风模型）是高阶用户愿意付费的功能。

### 9. 其他海外写作相关
- **Grammarly**：仅做句子级润色，无叙事记忆，定位「最后 15% 的润色手术刀」。
- **Jasper**：营销文案为主，可生成故事大纲与对话初稿。

## 1.3 剧本/短剧 AI Agent

### 10. 小云雀 AI 短剧 Agent（字节跳动）
- **定位**：一站式 AI 短剧内容创作平台，2026 年 3 月上线的行业智能体（搭载 Seedance 2.0）。
- **核心能力**：上传剧本（最高 10 万字）→ 确认画风（2D/3D/仿真人）、画幅、旁白 → 自动完成故事蓝图构建、角色设计、分镜生成 → 一键成片；能深度解析完整剧本，梳理世界观、时间线、人物关系，分析角色全生命周期形象变化。
- **标杆案例**：60 集短剧《万兽独尊》，5 人 8 天完成（传统流程需 3-6 个月），上线 4 天播放破亿。
- **启示**：「剧本 → 分镜 → 成片」全链路是短剧 Agent 的终局形态。

### 11. 火山剧创 1.0（火山引擎）
- **定位**：多智能体协同的短剧工业化平台（2026 年 5 月发布）。
- **核心能力**：深度适配 Seedance/Seedream 模型，短剧制作周期缩短 80%+；全链路各核心节点均向用户开放编辑权限（人类保有最终控制权）。
- **启示**：「每个节点可编辑」是专业团队接受 AI 的前提。

### 12. 爱奇艺·纳逗 Pro
- **定位**：结合爱奇艺内容经验的创作智能体矩阵（规划近 70 个智能体）。
- **核心能力**：**小说一键转剧本**、专业剧本评估与分析、精细光线调整与运镜定义（导演意图表达）。
- **启示**：「小说转剧本」+「剧本评估打分」是长视频平台验证过的高价值功能。

### 13. 昆仑万维 SkyReels
- **定位**：AI 短剧创作平台（剧本生成、分镜、BGM、对白全包）+ 文生/图生视频。
- **启示**：剧本与视频生成一体的「包圆」式产品正在涌现。

### 14. 阿里云百炼·全妙
- **定位**：面向 AI 短剧/漫剧的剧本创作工具。
- **核心能力**：剧情结构搭建、人物关系设定、台词与分镜生成。

### 15. 中劢 AI（剧本工厂 + 文生视频）
- **核心能力**：内置短剧剧本工厂，覆盖甜宠、悬疑、都市逆袭、古风奇幻、二次元漫剧等数十类题材；输入核心创意即产出带人物设定、场景对白、镜头提示的**标准化分集剧本**；已有剧本一键导入自动拆解为分镜脚本（标注运镜、动作、画面风格）。
- **启示**：「标准化分集剧本 + 自动拆分镜」是商业短剧团队的真实采购点。

### 16. 短剧大模型微调派（行业实践）
- 用短剧领域语料（热门剧本、爆款台词）对基座模型做领域微调；结构化 Prompt 内置「黄金三秒」「强冲突」「反转」等模板；输出含「场次、对白、运镜建议、情绪标签」的专业分镜脚本。

## 1.4 竞品格局总结

| 维度 | 行业现状 | 我们的机会 |
|---|---|---|
| 长篇一致性 | 普遍 10-15 章后开始角色/设定漂移 | 状态化内存（角色快照+伏笔账本）做成核心卖点 |
| 全自动 vs 协同 | 全自动质量不稳，纯协同效率低 | 「全自动流水线 + 任意节点可介入调校」双模式 |
| 小说→剧本 | 仅爱奇艺纳逗等少数支持 | 打通小说/剧本双文体互相转换 |
| 短剧工业化 | 剧本与分镜、成片割裂 | 剧本侧做深：分集节奏、钩子密度、爽点量化评估 |
| 质量评估 | 几乎无专业剧本/小说评估 Agent | 内置「主编/评审 Agent」给出可执行修改意见 |
| 文风个性化 | NovelAI 微调门槛高 | 一键「文风克隆」（粘贴样章即学） |

# 第二部分：产品文档（PRD）

## 2.1 产品概述

- **产品名（暂定）**：瀚霖创作引擎
- **一句话定位**：以多 Agent 架构驱动的「小说 + 剧本」双文体创作大模型与创作平台 —— 既能一句话全自动成书/成剧，也支持创作者在任意节点介入调校。
- **核心理念**：AI 主导生成，人类主导审美；速度交给模型，灵魂交给作者。
- **目标形态**：底座大模型（创作专用微调）+ 多 Agent 工作流引擎 + 创作者工作台（Web）。

## 2.2 目标用户与场景

| 用户层 | 画像 | 核心场景 |
|---|---|---|
| 网文作者（个人） | 兼职/全职写手，追求日更字数 | 大纲生成、卡点救场、续写、扩写、日更提速 |
| MCN / 短剧公司 | 批量生产分集短剧剧本 | 题材批量起稿、分集节奏控制、拆分镜、剧本评估 |
| 影视/版权机构 | IP 改编评估与开发 | 小说转剧本、改编可行性评估、人物关系梳理 |
| 文学爱好者 | 零基础新手 | 一句话成书、标签化选题、模板引导 |

## 2.3 产品能力总览（含优先级）

### A. 底座模型能力（训练侧）

| 编号 | 能力 | 说明 | 优先级 |
|---|---|---|---|
| A1 | 创作领域继续预训练/SFT | 网文全品类 + 经典文学 + 剧本（影视/短剧/话剧）语料微调，掌握类型套路与文体规范 | **P0** |
| A2 | 超长上下文与长程一致性 | 支持 20 万字级以上上下文；角色、设定、时间线跨章不漂移 | **P0** |
| A3 | 结构化输出能力 | 稳定输出大纲/角色卡/分集表/分镜脚本等 JSON/模板结构 | **P0** |
| A4 | 指令遵循与风格控制 | 按 POV、时态、文风、禁忌词等约束稳定生成 | **P0** |
| A5 | 文风克隆（Few-shot 风格迁移） | 粘贴 1-3 篇样章即可模仿作者文风 | P1 |
| A6 | 剧本评估能力（评审模型） | 节奏、钩子密度、爽点/泪点分布、结构完整性的量化打分 | P1 |
| A7 | 多模态理解/生成接口 | 角色图、场景图、分镜草图生成（对接图像模型） | P2 |
| A8 | 个人文风微调（LoRA 托管） | 用户级 LoRA，训练「我的分身模型」 | P2 |

### B. Agent 工作流（引擎侧）—— 参考 ainovel-cli 架构升级

| 编号 | 功能 | 说明 | 优先级 |

| B1 | 总调度 Agent（Coordinator） | 一句话需求 → 全自动成书/成剧的闭环调度，支持断点续跑 | **P0** |

| B3 | 写手 Agent（Writer） | 章节闭环：加载上下文 → 回读前文 → 规划本章 → 写作 → 一致性自检 → 提交 | **P0** |
| B4 | 状态化记忆系统 | 角色快照、设定集（Lorebook）、伏笔账本（埋设/推进/回收追踪）、时间线、前情摘要 —— 全书结构化事实层 | **P0** |
| B5 | 一致性校验 Agent | 对照事实层检查每章逻辑、角色言行、设定冲突，自动修正 | **P0** |
| B6 | 评审/主编 Agent（Editor） | 弧级/卷级评审：结构问题、节奏雷同、水文检测，输出裁定与重写范围 | **P1** |
| B7 | 剧本分集 Agent | 按短剧节奏模型（黄金三秒/强冲突/集末钩子）拆分集、控节奏 | **P1** |
| B8 | 分镜脚本 Agent | 剧本 → 含场次/对白/运镜建议/情绪标签的标准分镜表 | P1 |
| B9 | 小说转剧本 Agent | 长篇小说 → 分集剧本自动改编（取舍、合并、视角转换） | P1 |
| B10 | 市场调研 Agent | 抓取平台热榜/热门梗，输出选题与卖点建议（联网） | P2 |
| B11 | 敏感内容与合规审查 Agent | 涉政/涉黄/涉暴/未成年人等红线检测与改写建议 | **P0**（商用前置） |

## 2.4 关键技术指标（验收标准）

| 指标 | 目标 | 优先级 |
|---|---|---|
| 长文一致性 | 100 章内角色/设定零硬冲突（自动校验通过率 ≥ 95%） | **P0** |
| 生成吞吐 | 单章（3000-5000 字）端到端 ≤ 3 分钟 | **P0** |
| 伏笔回收率 | 埋设伏笔 100% 登记，回收率可追踪、烂尾可告警 | **P1** |
| 剧本节奏达标 | 分集剧本每集含开场钩子和结尾悬念，通过评审 Agent 验收 | **P1** |
| 文风相似度 | 克隆文风盲评「像本人写的」≥ 70% | P1 |
| 人工干预率 | 全自动模式可用初稿人工修改量 ≤ 20% | P1 |

## 2.5 合规与版权（P0，不可后置）

- 训练语料版权合规审查与授权链路。
- 生成内容版权归属条款（参照行业惯例：用户所有，平台限定训练使用权需明示且可 opt-out）。
- AI 生成内容标识（按监管要求添加显式/隐式标识）。
- 防抄袭检测：生成文本与语料库/公开作品相似度查重。

## 2.8 风险与对策
